# AI Customer Support Agent

An AI-powered customer support system built using Python, LangGraph, LangChain, and Google Gemini.

## Features

- FAQ answering using Retrieval-Augmented Generation (RAG)
- Order tracking using SQLite
- Refund eligibility checking using business rules
- Complaint management and support ticket creation
- Stateful conversations and conditional workflow routing
- Human-in-the-loop escalation
- Interactive Streamlit interface

## Tech Stack

- Python
- LangGraph
- LangChain
- Google Gemini
- Chroma
- SQLite
- Streamlit

## Project Status

Currently under development. Features will be implemented and tested incrementally.
